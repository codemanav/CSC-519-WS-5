

#  INTRO TO ANSIBLE II


## LEARNING GOALS

In this workshop, the goal is to use Ansible in new ways using separate "plays" or "playbooks".  One focuses on security and the second and main part of this working involves using ansible to create two variants of the same configuration, and then gathering emperical data about the performance.

The first configuration uses Workshop-4 as a starting point, and assumes that you have a `Node.js` app that you can launch from a playbook.

## 2. "Security First" -- Set up a secuiry-oriented Ansible playbook

Create an ansible playbook file in your workshop directory called `0-security-updates.yaml`.    

Using web resources, add ansible playbook elements to your security file that checks for and applys all security patches to all managed hosts.
This playbook should run on all managed hosts in your inventory.


## 3. NodeJS + Database: Setup Configuration 1

Create an ansible playbook file in your workshop directory called `1-setup-config.yaml`.    

This playbook should install and configure these elements on a single managed host:
* `NodeJS` / `npm`
* A persistent data store (like `mysql` or `redis`)
* your app (see below)


### Populate the datastore.

Using Ansible, populate the datastore using the contents of the file `rand-x-y-data.csv`, included in the forked workshop repo.
This Comma Separated Value (`.csv`) file contains 10,000 random `x,y` points between `(0,0)` and `(100,100)` and the file contains a header row.


### Create a `NodeJS app` to Query the database

Create a `NodeJS app` that responds to `http` queries on port 80. The app should geneate a random x,y point between `(0,0)` and `(100,100)`, then search the database for the closest point, then display the closest point from the database as well as the cartesian distance from the random point to the closest point in the dataset.

Repeat visits to the homepage of the app should show a different random point on each visit.


## 4. NodeJS + Database: Setup Configuration 2

To fulfill this part you'll need to set up a *second virtual machine* (VM2) that will host a database.


Create an ansible playbook file in your workshop directory called `2-setup-config.yaml`.    

This playbook should install these elements on two separate managed host:
* (VM1) `NodeJS` / `npm`
* (VM1) Your app.
* (VM2) A persistent data store (like `mysql` or `redis`)

This configuration runs mostly the same `NodeJS app` as the previous step, but now use ansible to configure the database on a separate machine.   Try to create your `NodeJS app` so that it takes the `db` connection information as a parameter.


## 5. Create a Program to Collect Data

Using the configuration generated by `1-setup-config.yaml`, write a program that measures how long (in milliseconds) it takes to query the homepage of the `Node.js` 30 times sequentially. Record both the time for each query and the total time.   

Now repeat this same data-gathering but using the `2-setup-config.yaml`, again, timing how long it takes (indiviually and in total) to query the homepage 30 times sequentially.

## 6. Visualize data
